# Cấu trúc thư mục Hiệu ứng AR (`hiệu ứng`)

Thư mục này chứa tài nguyên hình ảnh PNG cho từng hiệu ứng AR của ứng dụng:

- `tai thỏ/` (hoặc `/hieu-ung/tai-tho/`):
  - `taitho.png`: Hình tai thỏ bông trắng hồng gắn trên đỉnh đầu (`headCrownCenter`).
  - `muitho.png`: Hình mũi thỏ hồng kèm trái tim gắn ở đầu mũi (`noseTip`).
  - `rautho.png`: Hình râu thỏ gắn ở vùng hai bên má (`leftCheekCenter` / `rightCheekCenter`).
- `tai mèo/` (hoặc `/hieu-ung/tai-meo/`)
- `hoa/` (hoặc `/hieu-ung/hoa/`)
- `tim/` (hoặc `/hieu-ung/tim/`)
- `sao/` (hoặc `/hieu-ung/sao/`)
- `sparkle/` (hoặc `/hieu-ung/sparkle/`)
- `ánh sáng mềm/` (hoặc `/hieu-ung/anh-sang-mem/`)
